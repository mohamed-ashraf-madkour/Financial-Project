# 💰 Financial Loan Analysis Dashboard

A financial data analysis project built using Python to analyze loan performance, borrower behavior, and credit risk patterns.

--------------------------------------------------------------------------------------------------


# 📌 Project Overview

This project focuses on transforming raw financial loan data into actionable insights that can support:
- Credit risk evaluation
- Loan portfolio monitoring
- Business decision-making
- Financial trend analysis

The analysis explores loan performance, repayment behavior, customer segments, and lending trends.

--------------------------------------------------------------------------------------------------


# 🎯 Project Goals

- Evaluate the overall health of the loan portfolio
- Compare Good Loans vs Bad Loans
- Analyze monthly lending and repayment activity
- Identify borrower segments driving loan demand
- Explore the impact of employment, home ownership, and purpose on loan behavior
- Detect differences between funded and received amounts

--------------------------------------------------------------------------------------------------

# 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Data Cleaning
- Data Visualization

--------------------------------------------------------------------------------------------------


# 📂 Project Features

## 📊 Loan Portfolio Overview
Provides a high-level summary of loan performance.

### Includes:
- Total funded amount
- Total received amount
- Loan status distribution
- Good vs Bad loans comparison

### Key Insight:
The majority of loans are performing loans, indicating relatively healthy portfolio performance.

--------------------------------------------------------------------------------------------------


## 📈 Monthly Lending Trends
Analyzes changes in loan activity across months.

### Includes:
- Loan issuance trends
- Repayment activity trends
- Seasonal lending patterns

### Key Insight:
Certain months show noticeable spikes in lending and repayment activity, reflecting seasonal financial behavior.

--------------------------------------------------------------------------------------------------

## 👥 Borrower Segmentation
Explores which customer groups drive the highest loan demand.

### Includes:
- Loan purpose analysis
- Employment length analysis
- Home ownership analysis
- Regional loan behavior

### Key Insight:
Debt consolidation and home-related purposes represent major drivers of loan demand.

--------------------------------------------------------------------------------------------------


## ⚠️ Risk & Repayment Analysis
Focuses on financial risk indicators and repayment gaps.

### Includes:
- Charged-off loan analysis
- Funded vs received amount comparison
- Repayment gap evaluation

### Key Insight:
A measurable gap exists between funded and received amounts, highlighting repayment timelines and potential risk exposure.


--------------------------------------------------------------------------------------------------


# 📊 Key Insights

- Most loans in the portfolio are classified as performing loans
- Seasonal patterns affect lending and repayment behavior
- Renters and mortgage holders contribute significantly to portfolio volume
- Debt consolidation is one of the top loan purposes
- Repayment gaps may indicate risk exposure and delayed collections
